## 落とし穴（cols2.py が解いていること）

- `fulltext` の zip に入っている `.txt` を連結すると `かかかかかがががか…` になって読めない。
  **同じ zip の `.json`（ブロックごとの xmin/ymin/xmax/ymax）を使う**
- **縦組みの表は「x帯＝1項目」「y＝方言→語釈→使用地方の順」**
- 🔴 **横に広いブロックは、隣り合う複数の項目の文字がOCRで1行にまとめられたもの。左から右へ均等に割って各帯に配る。**
  これをやらないと語頭の1字が落ちて語が引けない
- ページ上端の `いいいいいい…` は**その面の全項目の頭文字**（あの部・いの部…）
- OCRは**濁点をよく落とす**ので、突き合わせは濁点・半濁点・小書きを畳んでから行う（`bulk2.py` の `n()`）

## 書誌の棚卸し

```sh
curl -s -A "Mozilla/5.0" "https://lab.ndl.go.jp/dl/api/book/search?searchfield=metaonly&keyword=方言&size=300"
```
⚠️ `keyword=茨城県 方言` のような県名＋語では 0件になる。**棚を丸ごと取って県名で grep する**。

## ページ画像を見る（第40回・2026-09-23 追加）

**OCRが `〓` で返した字は「資料に無い」ではなく「読めていない」だけ。** 画像は別APIで取れる。

```sh
# fulltext API とは別ホスト。R + 0埋め10桁のコマ番号
curl -s -A "Mozilla/5.0" -o p50.jpg \
  "https://www.dl.ndl.go.jp/api/iiif/868659/R0000000050/full/full/0/default.jpg"
```

- native は 4000px 前後。**1字あたり約100px しかない**ので、6〜9倍に拡大しても確実に読めるとは限らない
- 縦組みは `.rotate(-90, expand=True)` で横に倒すと読みやすい。行の切り出しは `cols2.py` が出す **x帯の中心**を使う
- ⚠️ **OCRのy座標は見出し（大きい字）と語釈（小さい字）で文字ピッチが違う。** 位置合わせは「ページ全体を1枚描いて目で当たりを付ける」のが早い
- 🔑 **読めても断定しない。** 1字を確定できない解像度なら `unconfirmed` のまま、**消去法の材料**（その語釈を別の行でどう組んでいるか）を note に残す

## 第43回（2026-09-26）に足りたこと＝**道具のバグ2つ**。ここが今いちばん大事

### 🔴 ① 本を開けたら「縦組みか横組みか」を先に見る。`cols2.py` は縦組み専用

`cols2.py`（＝x帯＝1項目）は**縦組みの本しか読めない**。横組みの表の本に当てると、
同じ行の文字が別の帯にばらけて **`bulk2.py` が 0件で返る**。これを「薄い本だった」と読むと本を1冊まるごと落とす
（実測：『青森県方言集』1232197 は最初 0件 → 道具を替えて **22語**）。

```sh
# 見分け方＝ブロックの座標を10件出す。1文字ずつの箱が横に等間隔で並び ymin が揃っていれば横組み
python3 -c "
import zipfile,json
z=zipfile.ZipFile('1232197.zip'); ns=sorted(n for n in z.namelist() if n.endswith('.json'))
for b in json.loads(z.read(ns[50]).decode())[:10]:
    print(round(b['xmin']),round(b['ymin']),round(b['xmax']),round(b['ymax']),'|',b['contenttext'][:40])"

python3 rows2.py 1232197.zip page 51            # 横組み＝y帯＝行方向に読む（第43回で追加）
python3 rows2.py 1232197.zip "區域|凡例"        # 検索の使い方は cols2.py と同じ
```

⚠️ **横組みの表は、見出しの行と語釈の行がずれる。上下1行を必ず一緒に読む。**
p53 は `y2181 形共 可愛い 南部、メラスァド` が **1行下の** `y2213 メゴイ(メンコイ)` の語釈だった。

### 🔴 ② `bulk2.py` はカナを畳まない＝カタカナ見出しの本では見出しが1件も当たらない

`bulk2.py` の `n()` は濁点・半濁点・小書きは畳むが、**カタカナ→ひらがなを畳んでいない**。
辞典側は平仮名（`めごい`）・本側はカタカナ（`メゴイ`）なので**見出しどうしは原理的に一致せず**、
ヒットしていたのは本文中の平仮名の例文への偶然一致だけ。実測 **12件 → 32件**。

```sh
python3 bulk3.py 1232197.zip 津軽弁   # ← カナ畳み込み入り。カタカナ見出しの本はこちらを使う
```

🔴 **`bulk2.py` にはまだ同じ穴が空いている**（縦組み用として残してある）。
**過去の回で「この本には無い」と書いた語のうち、カタカナ見出しの本が相手だったものは再検査の余地がある。**

### 🔑 ④ この棚で原理的に埋まらないのは〈戦後語〉と〈語尾・助動詞〉の2層

- 第42回＝戦後に定着した語（じゃみじゃみ／つるつるいっぱい）は明治〜昭和初期の県方言集に無い
- 第43回＝**語尾・助動詞・丁寧語も無い**。『南部方言集』の凡例に
  **「一品詞語格を論ずるは本篇の主旨にあらざるを以て須く之を省けり」**と明記。`がんす` `んだべ` は2冊とも0件
- 🔑 だから `南部弁 〜がんす／んだ・んだべ`・`神戸弁 〜とん？` は**NDLを何冊開けても出ない**。別系統へ回す
